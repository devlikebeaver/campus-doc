# 검증 기록

## 0.1.1 공개판 · 2026-10-01

공개판은 원본 문서·실제 사업 데이터·원본 CI·네이티브 바이너리 조각을 제외한 두 HWPX 컬렉션과 코드로 구성한다.
공개 예시 컴포넌트는 plan 16개, report 23개다.

| 항목 | 상태 | 증거/방법 |
|---|---|---|
| Windows x64 폴더 내부 런타임 준비 | 통과 | 공식 배포와 고정 wheel을 새 `runtime/`에 다운로드·해시 확인·실행 |
| Python/Node 사용 | 통과 | 준비한 Python 3.13.16와 Node 22.23.3 직접 실행 |
| 의존성 실제 import | 통과 | python-hwpx 6.6.0, lxml 6.1.3, olefile 0.47 |
| 공개 HWPX 예시 생성 | 통과 | plan/report 생성 후 ZIP CRC, XML, 스타일 참조, 병합 셀 검사 |
| HWPX 내용 편집 | 통과 | 공개 예시 제목 교체 후 재검사 |
| 네이티브 HWP 고정 길이 편집 | 통과 | 합성 HWP의 부서명 교체, 비텍스트 레코드와 OLE 스트림 검사 |
| 컴포넌트·양식 회귀 검사 | 통과 | check.py, check_library.py |
| 중앙 목록·추출 회귀 검사 | 통과 | check_registry.py |
| 공개 자원의 내부 메타데이터 검사 | 통과 | 원본 이미지 설명 3곳 제거, 계산 필드 캐시 12곳을 합성값 0으로 초기화; check_public_assets.py |
| 공개판 원본·실제 내용·CI 이미지 제외 | 통과 | 추적 파일 98개와 내부 ZIP 검사; 원본 이미지 바이트 미포함 |

| GitHub Windows/Linux 새 환경 검사 | 통과 | [새 공개 저장소 실행 기록](https://github.com/devlikebeaver/campus-doc/actions/runs/36871273076): 익명 자원 검사와 문서·컴포넌트·목록 회귀 검사 |
| 한컴에서 공개 예시 화면 비교 | 미검증 | 구조·바이너리 검사와 별도 판정 |
| 임의 사용자 문서 전체 호환성 | 미검증 | 문서별 입력·페이지 렌더링 필요 |
| Gemini 앱 링크→준비→파일 반환 | 미검증 | 로컬 실행 성공으로 대체하지 않음 |

설치·스모크의 실제 결과는 사용자의 `runtime/setup-status.json`, `runtime/smoke-result.json`에 남는다.
개인 경로가 포함될 수 있으므로 원본 실행 로그를 공용 저장소에 자동 커밋하지 않는다.

## 검사별 범위

- `check_public_assets.py`: 원본 이미지 파일명·로컬 경로 제거, 중립 그림 설명, 합성 계산 캐시 검사
- `check.py`: rich run과 private glyph 유지, 글자 스타일, 표 병합, 고정 슬롯 길이 초과 거부
- `check_library.py`: 새 문단 생성, 컴포넌트 버전, 양식의 버전 고정, 스타일 변경 분리,
  개체 ID 중복 방지, 문서 내용만 수정, 버전 충돌 거부, 기본 자원 불변
- `check_registry.py`: 전용 폴더 추출, 재귀 자식 트리, 반복 검토 이력, 원형 XML 재조합,
  추가 폴더 발견, 기관 조건 선택, 후보 충돌, 기본 선택, 비활성·구조 실패 제외,
  임의 문단과 다중 섹션 추출, 외부 폴더 등록, 원본 불변

렌더링에 영향을 주는 새 변경은 해당 페이지의 화면 비교를 추가한다.
글꼴 이름·코드포인트·문서 레코드가 같아도 설치된 글꼴과 렌더러에 따라 외형이 다를 수 있다.
